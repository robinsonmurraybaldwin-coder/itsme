# P&L 영상 수정 툴킷 (Vantage 웹 화면)

Vantage 웹 트레이딩 화면 녹화본에서 **손익(P&L)만** 원하는 금액대로 자연스럽게 바꾸는 파이프라인.
차트·시세·DEMO 배지·오디오·비(非)Vantage 구간은 손대지 않음.

## 사용법
```bash
python3 pnl_edit.py 소스.mp4 결과.mp4 --lo 9994 --hi 10355
```
- `--lo`, `--hi` : 손익 시작/끝 금액 (lo에서 hi로 완만히 상승하며 그 안에서 자연 변동)
- ffmpeg, Pillow, numpy, Inter 폰트(`/usr/share/fonts/opentype/inter/`) 필요

## 핵심 원리 (이게 "진짜처럼" 보이게 한 포인트 — 재사용 전 필독)

1. **폰트 = Inter.** Vantage 웹 UI 폰트가 Inter다.
   - 패널 숫자: Inter **Regular ~12px**
   - 차트 SELL 알약 숫자: Inter **SemiBold** 인데 **가로로 압축**된 글꼴(세로는 크고 가로는 좁음).
     → SemiBold로 렌더한 뒤 **가로만 압축(resize)** 해서 슬롯 폭에 맞춘다. 안 그러면 넘침.

2. **색 = muted green `~(95,191,146)`, 불투명도 ~0.8.** 진한 채도 초록(완전 불투명) 쓰면 혼자 튄다.
   알약 안 다른 텍스트들과 같은 농도로 맞춰야 자연스럽다.

3. **알약 배경은 반투명** (뒤 차트가 비침). **불투명 박스 깔지 말 것.**
   → 옛 숫자 **초록 픽셀만** 가로 보간으로 지우고(inpaint), 새 숫자를 그 위에 올린다.
   → inpaint 영역은 **숫자 슬롯만** (왼쪽 `13.88랏은`까지 먹으면 그 글씨가 흰색으로 짤림).

4. **움직임 = 원본의 실제 변동 "타이밍"을 그대로 재현.**
   실제 손익 = `(진입가 - 매도호가) × 랏 × 100` 이라 **TICK(=0.01×랏×100=13.88) 배수로만** 변함.
   임의 지터 ❌. 원본 숫자 크롭의 프레임 차분으로 **언제 바뀌는지**를 뽑아서, **그 프레임에서만** ±틱.
   → 멈출 때 멈추고(긴 홀드), 틱할 때만 움직임 = 원본과 같은 리듬. ("매초 변동" 안 함)

5. **연동 필드는 한 pnl 값에서 매 프레임 재계산:**
   ```
   equity       = BALANCE + pnl
   free_margin  = equity - USED_MARGIN
   margin_level = equity / USED_MARGIN * 100
   pct          = pnl / USED_MARGIN * 100
   ```
   (BALANCE, USED_MARGIN은 영상에서 1회 읽음. 마진수준 게이지 아이콘은 보존.)

## ⚠️ 좌표는 영상마다 다시 재야 함
`pnl_edit.py`의 `CFG` 안 모든 픽셀 좌표는 **이 녹화(1920×1040, 그 브라우저 줌/스크롤)** 기준.
해상도·줌·패널 스크롤이 다른 새 녹화는 좌표를 다시 측정해야 한다. **방법은 그대로, 숫자만 갱신.**

### 좌표 재측정 순서
1. 전 프레임 추출 → Vantage 전경 구간 찾기(초록 시그니처 2곳).
2. 기준 프레임에서 각 숫자 박스의 `(clear_x0, baseline_y)` + 우측 정렬 x 측정.
3. 차트 알약: `은` 끝 → `+` 시작(공백) → 숫자 끝 → `×` 위치. 숫자 슬롯 폭/시작 확정.
4. 원본 숫자 초록의 **core 색**(가장 채도 높은 픽셀 평균)·불투명도 측정 → `green_pill`.
5. 원본 숫자 폭 vs Inter 자연 폭 비율 → `chart_tw`(압축 폭).
6. `used_margin`(여백 사용), `balance`(잔액), `tick`(=0.01×랏×100) 읽기.

## 변경 이력에서 나온 교훈 (같은 실수 반복 금지)
- 불투명 흰/회색 박스 → 패치처럼 뜸. 반드시 inpaint + 반투명 유지.
- Liberation/Arial 폰트 → 서체가 달라 티남. Inter 필수.
- 5자리(1만대)는 4자리보다 넓음 → 압축 렌더로 슬롯에 맞춤(칸 넓히기 대안도 있으나 ×·테두리 이동 필요해 비추).
- inpaint가 왼쪽 텍스트까지 먹으면 글씨 짤림 → 슬롯만.
- 진한 초록 → 반투명 muted green으로.
