# 연습뱅크 (프론트엔드 연습용)

은행 앱 화면 녹화 영상의 흐름을 따라 만든 **연습용** 웹앱입니다. HTML/CSS/순수 JavaScript(ES Modules)만 사용합니다.
계좌, 이름, 은행은 모두 가짜이고 실제 금융 기관과는 관계없습니다.

## 화면 흐름

```
홈 ──이체──▶ 누구에게 보낼까요? ─▶ 은행 선택 ─▶ 얼마를 보낼까요?(키패드) ─▶ ○○님께 ○원을 보낼까요? ─▶ 완료
 │                                                                                         │
 ├─ 최근 이체내역 ─▶ 이체결과조회 ─▶ 이체확인증(공유하기)                                       └─ 거래내역조회
 ├─ ☰ ─▶ 전체메뉴(검색, 최근/조회/이체·출금 탭)
 └─ 맞춤메뉴 ─▶ 거래내역조회 ─▶ 상세거래내역(메모 등록, 다시이체)
```

**한 페이지 앱(SPA)** 이라서 HTML 파일은 `index.html` 하나뿐입니다.
화면 5개는 `index.html` 안의 `<template>` 에 들어 있고, `js/app.js`(라우터)가 주소의 `#/이름`을 보고 화면을 바꿔 그립니다.

| 주소 | 화면 (`<template>` / JS) | 연습 포인트 |
|---|---|---|
| `#/home` | 홈: 계좌 카드(스와이프), 이체/ATM출금, 맞춤메뉴 (`tpl-home` / `home.js`) | 반응형 레이아웃, 이벤트 위임 |
| `#/transfer` | 이체 4단계 + 은행 선택·키패드·통장 표기 시트 (`tpl-transfer` / `transfer.js`) | 상태(state) 관리, 단계 전환, Promise 로 시트 결과 받기 |
| `#/history` | 거래내역조회, 상세거래내역, 채우기 (`tpl-history` / `history.js`) | 필터, 바텀시트, 메모 저장 |
| `#/result` | 이체결과조회 → `#/result?id=5` 이체확인증 (`tpl-result` / `result.js`) | 주소로 화면 나누기, 검색, 공유하기(Web Share API) |
| `#/menu` | 전체메뉴 (`tpl-menu` / `menu.js`) | 데이터로 화면 그리기, 검색 강조, IntersectionObserver |

화면 JS 는 모두 `mountXxx(params)` 함수 하나를 내보내고, 화면에 들어올 때마다 새로 실행됩니다.
`params` 는 주소의 `?` 뒤 값이에요. (예: `#/transfer?from=1` → `params.get("from")` 은 `"1"`)

공통 코드:
- `js/app.js`: 라우터. 주소가 바뀌면 이전 화면 정리 → 템플릿 복사 → `mount` 실행
- `js/api.js`: 서버 요청은 전부 여기. Supabase 설정이 없으면 같은 규칙으로 localStorage 사용
- `js/ui.js`: 금액·날짜 포맷, 아이콘, 바텀시트(`openSheet`), 토스트, 공유, 다크 모드
- `css/style.css`: 색은 모두 `:root` 변수 → 다크 모드는 변수만 바꿈

## 실행

원본은 JS 파일이 나뉘어 있어서(ES Modules) **더블클릭으로는 동작하지 않습니다.** 로컬 서버로 여세요.
(CSS·JS 를 전부 합친 HTML 한 파일 버전은 더블클릭으로도 열려요.)

```bash
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다. VS Code의 **Live Server** 확장을 써도 됩니다.

## 계좌 데이터: Supabase / 로컬 모드

현재 `js/config.js`에 Supabase 프로젝트가 연결되어 있습니다.

- **Supabase 모드**: SQL Editor 에 `supabase/schema.sql` 전체를 붙여넣고 Run 하면 테이블·함수·가짜 데이터가 만들어집니다.
  다시 실행하면 처음 상태로 돌아갑니다.
- **로컬 모드**: `js/config.js`의 URL과 키를 비우면 브라우저 `localStorage`에 저장합니다.
  처음 상태로 되돌리려면 개발자도구 콘솔에서 `localStorage.clear()`를 실행하세요.
- ⚠️ `js/config.js`에는 공개용 anon 키만 넣으세요. `service_role` / `secret` 키는 절대 안 됩니다.

돈이 움직이는 작업(이체, 채우기, 메모)은 프론트에서 테이블을 직접 바꾸지 않고
DB 함수(`transfer`, `deposit`, `set_memo`)를 호출합니다. 잔액 확인 → 차감 → 기록이 한 번에 처리돼요.

## 화면 크기별 모양

- `~499px` (진짜 휴대폰): 앱이 화면을 꽉 채움. 휴대폰 자체 상태바가 있으니 가짜 상태바·버튼은 숨김
- `500px~` (컴퓨터·태블릿): 가운데에 휴대폰 틀 + 상태바(현재 시각, 배터리) + 안드로이드 버튼(`|||` 전체메뉴, `○` 홈, `<` 뒤로)

휴대폰 틀 안에 시트·탭바가 붙는 원리: `.screen` 에 `transform` 을 주면
그 안의 `position: fixed` 요소는 브라우저 창이 아니라 `.screen` 기준으로 자리를 잡아요.
