# 연습뱅크 (프론트엔드 연습용)

은행 앱 화면 녹화 영상의 흐름을 따라 만든 **연습용** 웹앱입니다. HTML/CSS/순수 JavaScript(ES Modules)만 사용합니다.
계좌, 이름, 은행은 모두 가짜이고 실제 금융 기관과는 관계없습니다.

## 화면 흐름

```
홈 ──이체──▶ 누구에게 보낼까요? ─▶ 은행 선택 ─▶ 얼마를 보낼까요?(키패드) ─▶ ○○님께 ○원을 보낼까요? ─▶ 완료
 │                                                                                         │
 ├─ 최근 이체내역 ─▶ 이체결과조회 ─▶ 이체확인증(공유하기)                                       └─ 거래내역조회
 ├─ ☰ ─▶ 전체메뉴(검색, 최근/조회/이체·출금 탭)
 └─ 맞춤메뉴 ─▶ 거래내역조회 ─▶ 상세거래내역(메모 등록, 다시이체)
```

| 파일 | 화면 | 연습 포인트 |
|---|---|---|
| `index.html` | 홈: 계좌 카드(스와이프), 이체/ATM출금, 맞춤메뉴 | 반응형 레이아웃, 이벤트 위임 |
| `transfer.html` | 이체 4단계 + 은행 선택·키패드·통장 표기 시트 | 상태(state) 관리, 단계 전환, Promise 로 시트 결과 받기 |
| `history.html` | 거래내역조회, 상세거래내역, 채우기 | 필터, 바텀시트, 메모 저장(POST) |
| `result.html` | 이체결과조회 → 이체확인증 | 해시(#) 라우팅, 검색, 공유하기(Web Share API) |
| `menu.html` | 전체메뉴 | 데이터로 화면 그리기, 검색 강조, IntersectionObserver |

공통 코드:
- `js/api.js`: 서버 요청은 전부 여기. Supabase 설정이 없으면 같은 규칙으로 localStorage 사용
- `js/ui.js`: 금액·날짜 포맷, 아이콘, 바텀시트(`openSheet`), 토스트, 공유, 다크 모드
- `css/style.css`: 색은 모두 `:root` 변수 → 다크 모드는 변수만 바꿈

## 실행

`fetch`와 ES Modules 때문에 **파일을 더블클릭해서 열면 동작하지 않습니다.** 로컬 서버로 여세요.

```bash
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다. VS Code의 **Live Server** 확장을 써도 됩니다.

## 계좌 데이터: Supabase / 로컬 모드

현재 `js/config.js`에 Supabase 프로젝트가 연결되어 있습니다.

- **Supabase 모드**: SQL Editor 에 `supabase/schema.sql` 전체를 붙여넣고 Run 하면 테이블·함수·가짜 데이터가 만들어집니다.
  다시 실행하면 처음 상태로 돌아갑니다.
- **로컬 모드**: `js/config.js`의 URL과 키를 비우면 브라우저 `localStorage`에 저장합니다.
  처음 상태로 되돌리려면 개발자도구 콘솔에서 `localStorage.clear()`를 실행하세요.
- ⚠️ `js/config.js`에는 공개용 anon 키만 넣으세요. `service_role` / `secret` 키는 절대 안 됩니다.

돈이 움직이는 작업(이체, 채우기, 메모)은 프론트에서 테이블을 직접 바꾸지 않고
DB 함수(`transfer`, `deposit`, `set_memo`)를 호출합니다. 잔액 확인 → 차감 → 기록이 한 번에 처리돼요.

## 테스트용 받는 계좌

| 은행 | 계좌번호 | 예금주 |
|---|---|---|
| 연습뱅크 | 123-111111-01-011 | 홍길동 |
| 가나은행 | 98765432101 | 김철수 |
| 다라은행 | 3333012345678 | 이영희 |
| 마바은행 | 110123456789 | 박민수 |
| 사아은행 | 3020000123456 | 최지우 |

내 다른 계좌(`123-456789-02-022`)로 보내면 그 계좌에 입금도 기록됩니다.

## 반응형 기준

- `~599px`: 휴대폰, 하단 탭바
- `600px~`: 계좌 카드 2장씩
- `768px~`: 가운데 정렬
- `1024px~`: 하단 탭바 → 왼쪽 사이드바, 홈 2단 레이아웃
